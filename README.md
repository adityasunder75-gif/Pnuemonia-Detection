# Pnuemonia-Detection
The description of the project is that there is a system of ai which detects the liung disease called pneumionia which inflammates the lungs.

**#REQUIREMENTS**
Run the following commands in your terminal or command prompt:

**Install TensorFlow:**

pip install tensorflow

**Install scikit-learn (for classification_report):**

pip install scikit-learn

*After running these commands successfully, the necessary modules (tensorflow, tensorflow.keras, and sklearn.metrics) will be available, and your Python script should run past the import statements.*
